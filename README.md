# Criando-um-Dashboard-de-Vendas-do-Xbox-com-Excel

# 📊 Dashboard de Vendas

Este projeto consiste na criação de um **Dashboard de Vendas no Excel**, com o objetivo de transformar dados brutos em informações visuais claras e úteis, facilitando a análise de desempenho e a tomada de decisões estratégicas.

## ✅ Objetivos

- Organizar e visualizar os dados de vendas de forma intuitiva.
- Facilitar a interpretação dos indicadores principais.
- Proporcionar insights a partir da análise gráfica.

## 📁 Estrutura do Projeto

O projeto é composto por:

- `dashboard_vendas_customizado.xlsx`: Arquivo Excel contendo o dashboard final com esquema de cores personalizado.
- `base.xlsx`: Base de dados original utilizada para alimentar o dashboard.
- `README.md`: Este arquivo, com a descrição do projeto e instruções de uso.

## 📊 Funcionalidades do Dashboard

- Visão geral de desempenho de vendas.
- Gráficos interativos para análise visual.
- Indicadores de destaque como total de vendas, ticket médio, número de clientes e mais.

## 🧮 Planilhas no Arquivo Excel

- `A̳ssets`: Recursos gráficos utilizados no dashboard.
- `B̳ases`: Dados brutos de vendas.
- `C̳álculos`: Tratamento e organização dos dados.
- `D̳ashboard`: Interface visual do dashboard.

## 🎨 Diferencial

Este dashboard foi inspirado em um modelo original, com **esquema de cores alterado** para uma identidade visual única e moderna.

## 🔁 Como Reproduzir

1. Faça o download do arquivo `dashboard_vendas_customizado.xlsx`.
2. Abra no Microsoft Excel (preferencialmente 2016 ou superior).
3. Navegue até a aba `D̳ashboard` para visualizar os dados e gráficos.
4. Atualize os dados na aba `B̳ases` se desejar gerar novos relatórios.

## 🚀 Tecnologias Utilizadas

- Microsoft Excel
- Gráficos dinâmicos
- Fórmulas e funções para manipulação de dados
